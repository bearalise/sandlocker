# SandLocker guest 内核跟进策略

| 项目 | 内容 |
| --- | --- |
| 版本 | v1.0 |
| 日期 | 2026-08-04 |
| 依据 | PRD v1.2 ADR-16（快照版本钉住与生命周期）、14.2-2（内核跟进策略待定项）、8.2（安全响应）、8.4（可靠性） |
| 状态 | 关闭 PRD 14.2-2 |

> 本文定义 SandLocker 自带精简 guest 内核的版本选择、安全补丁跟进、重建与保留策略。构建实现见 `scripts/build-kernel.sh` + `scripts/kernel-fragment.config`。

## 1. 版本钉选

- **主线钉 6.6 LTS 系列**（`build-kernel.sh` 默认主版本 6.6）。6.6 是长期支持内核，维护窗口覆盖到 2026 年之后，稳定补丁流持续。
- 构建脚本解析 kernel.org 上 **6.6.y 的最新补丁版本**并钉住，产物记录完整三元组到 `build/kernel/build-info.txt`（`version` / `built_at` / `baseline` / `fragment` / `gcc`）。
- **下限 ≥5.18**（ADR-12）：vmgenid CRNG reseed 是快照克隆熵防护的前提；6.6 远高于此，硬满足。
- 基线配置取 Firecracker 官方 `microvm-kernel-ci-x86_64-6.1.config`，经 `olddefconfig` 适配 6.6，叠加 `kernel-fragment.config`（vmgenid / vsock / virtio / ext4 / dm-thin 前置），并**逐项校验 fragment 生效**（静默丢配置即构建失败）。

## 2. 安全补丁跟进

- **跟踪源**：kernel.org 6.6.y 稳定发布、[linux-cve-announce]、发行版安全公告（对 6.6.y 的回合补丁）。
- **补丁 SLA**：高危 guest 内核 CVE（可导致 guest→host 逃逸、或 guest 内提权配合逃逸链）**48h 内**产出重建的内核镜像并推进快照重建（对齐 PRD 补丁 SLA 口径）。中低危随下一个 6.6.y 常规滚动。
- **评估边界**：仅评估对 **microVM guest 攻击面**实际可达的 CVE——精简设备模型（virtio-net/blk/vsock + 串口，`pci=off`）大幅收窄面；不影响该设备集的驱动/子系统 CVE 可降优先级，须在响应记录中注明判定理由。

## 3. 重建触发与自动化

| 触发 | 动作 |
| --- | --- |
| 6.6.y 有新补丁版本 | CI 定期（或安全事件驱动）重跑 `build-kernel.sh`，产出新 `vmlinux-<ver>` |
| 高危 CVE（48h SLA） | 立即重建 + 触发模板快照重建 |
| 内核/VMM 版本变更 | 模板预烘焙快照按（模板版本, 内核版本, VMM 版本）三元组失效并重建（ADR-16） |

- **模板快照**视为可再生缓存：内核升级后 CI 自动重建，用户模板经 `sandlocker build --rebuild-all`（M1+ 能力）。
- **可复现性**：构建脚本钉基线 config + fragment + 记录 gcc 版本；同版本三要素可复现同内核（`.sha256` 存档）。RUN 型不可复现项不涉及内核构建。

## 4. 版本保留与快照兼容（ADR-16）

- 节点**保留 N-1 内核镜像 + Firecracker 二进制**，以承接版本钉住的 paused 用户快照（FC 快照绑定内核/VMM 版本）。
- paused 用户快照按三元组钉住，仅可恢复到运行兼容版本的节点；**默认保留期 7 天**（可配），过期回收。
- 恢复旧内核快照返回**「未打补丁 guest 内核」警告**。
- 跨版本快照升级（唤醒→新版本重打快照）列 P2。

> 说明：本策略中「快照重建/保留/N-1」为 M1+ 快照引擎落地后的运行形态；M0 阶段仅内核构建管线（第 1–3 节）已实现并经基准 CI 的 `validate` job 每 PR 验证可构建性。
