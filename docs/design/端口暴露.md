# 端口暴露（Port Exposure）——外部访问 VM 内动态服务

让沙箱（microVM）里跑的动态 Web 应用（Next.js / Vite / 任意 HTTP 服务）能被外部经一个稳定地址访问，**支持完整协议**：任意 HTTP 方法、流式/SSE、WebSocket/HMR、keep-alive。

## 与数据面网关 `/gw/*` 的区别

| | 一次性 ticket（`/gw/*`，ADR-22） | 端口暴露（本特性，FR-3.3） |
|---|---|---|
| 用途 | exec / 取文件 / 看日志 / 单次探活 | 承载完整动态 Web 站点 |
| 连接 | 一次性签名 URL，一 URL 一请求一路径 | 稳定地址，任意 path/方法/连接数 |
| 传输 | 手写 HTTP/1.0 单 GET，整包缓冲 | **纯 L4 裸字节透传**（对上层协议不可见） |
| 鉴权 | 一次性 HMAC 验签 | **无每请求鉴权**（地址即能力，方案取舍） |

## 用法

```bash
# 起沙箱，在里面跑 Next.js（监听 0.0.0.0:3000 或 127.0.0.1:3000）
sandlocker exec <id> -- sh -c 'cd /app && npm run start &'

# 暴露：默认 bind 127.0.0.1，host 端口由 OS 分配
sandlocker expose <id> 3000
# → http://127.0.0.1:44321/

# 指定 host 端口 / 对外 bind（对外需守护带 --expose-allow-public）
sandlocker expose <id> 3000 --host-port 8080 --bind 0.0.0.0

# 撤销
sandlocker unexpose <id> 3000
```

REST：`POST /v1/sandboxes/{id}/expose` `{port, host_port?, bind?}` → `{url, bind, host_port, guest_port}`；
`DELETE .../expose/{guest_port}`；`GET .../exposes`。SDK：`client.expose()/unexpose()/list_exposes()`（Python/TS）。

## 拓扑

```
外部 client ──TCP── host 监听器(bind:host_port) ──vsock 隧道── guest sl-envd handle_connect
            ──splice_bidi── guest 127.0.0.1:guest_port（你的应用）
```

host 侧与 guest 侧都是全双工裸字节 splice，不解析 HTTP，故任意协议原样穿透。

## 约束与安全（务必读）

- **仅 FC（vsock）后端**：gVisor 无 vsock，返回 400。
- **无鉴权（方案取舍）**：纯 L4 透传无法注入鉴权/审计/限流——能连到 `host_port` 者即得应用原始访问。
  - 默认只 bind `127.0.0.1`（仅本机）。
  - 对外 bind（`0.0.0.0`/网卡 IP）须守护带 `--expose-allow-public`，且仅限**可信网络**；远程访问优先走 SSH 隧道。
- **无 TLS**：纯 http（ADR-22 的 TLS 终结是集群版目标）。
- **应用须监听 `127.0.0.1` 或 `0.0.0.0`**：sl-envd 从 guest 内 dial `127.0.0.1:guest_port`。
- **框架 host 校验**：Next.js `dev`/`start` 默认不校验 host，可直接用；**Vite / webpack-dev-server** 需设 `allowedHosts`（透传不改写 Host 头）。
- **活跃连接不顺延租约**：沙箱可能在浏览器连着时被 idle/TTL 回收——请设足够 `ttl`/`idle` 或周期 `keepalive`。
- **端口冲突**：指定的 `host_port` 被占用即 400。
- **生命周期**：沙箱 destroy 或被 reaper 回收时，其暴露监听器自动拆除。

## 验证

`sl-node --expose-reconcile <模板目录>`：真 FC microVM 上端到端对账——L4 透传、并发（guest 每连接一线程）、
拆除后端口释放、destroy 零残留；模板含 node 时另证 keep-alive / 非 GET+body / SSE 流式增量推送。
CI `expose` job 常态回归。
