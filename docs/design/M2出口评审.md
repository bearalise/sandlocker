## 1. 验证问题结论（M2-Q1–Q12）

| # | 问题 | 结论 | 证据 |
| --- | --- | --- | --- |
| **M2-Q1** | jailer `--netns`+veth/NAT 真出口 + 恢复钩子写真 nft allow，能否使"策略生效前无发包窗口"从结构性升级为 live 端到端 | ✅ 通过 | `--net-live-reconcile`：真 microVM 进 per-instance 具名 netns，forward-hook 门禁 resume 前 ensure（默认 drop）→ 无 allow 被拒 / add_allow 放行（nft drop/accept 计数器为证）+ NAT masquerade + 销毁无残留。`--net-live` 时序探针 root-live 档 margin 真实非 0。CI `net-live` job（W1/W2） |
| **M2-Q2** | 预热池池命中 create P50 ≤100ms 是否可达（**硬出口①**） | ✅ 通过 | `--pool-bench`：冷 P50≈100ms → **温池 warm P50≈70ms**（copy 移出关键路径）→ **热池 hot P50≈48ms**（park/activate，spawn+load 也移出）。裸金属 `POOL_P50_BUDGET_MS=100` hard-gate；bench-light gate 回归+分位入库（W4/W5） |
| **M2-Q3** | Sandbox ABI 抽象 + 能力模型（ADR-14）是否成立 | ✅ 通过 | `SandboxBackend` trait + `Capabilities` 位集；FC 重构到 trait 之后无回归；`required_capabilities` 创建期校验，不满足返 `UNSUPPORTED_BY_BACKEND`（禁运行期静默降级）；`GET /v1/backends`。`--abi-contract` 能力矩阵（W6/W8） |
| **M2-Q4** | gVisor(runsc) 后端能否接入并与 FC 可切换（**硬出口②**） | ✅ 通过 | `GvisorBackend` 实现同一 ABI（rootless `runsc run --detach`+`exec`；能力集**空**——显式无 prebake/pause/fork）；`--gvisor-reconcile` create/exec(uname=runsc)/fs/destroy 零残留；`--abi-contract` `both_backends:true switchable:true`（W7/W8） |
| **M2-Q5** | pause/resume 用户 API（FR-1.4）是否正确、不破坏克隆熵 | ✅ 通过 | `POST /pause|/resume|/fork`（能力门控 pause_resume/snapshot_fork）；`--q5-reconcile`：pause→fork×2→resume，A0/A1/B/C 的 machine-id 两两互异 + 两 fork 的 rng/session-key 互异（reinit 每次换发）；fork 复用父 rootfs=不刷新安全边界（文档明示）（W9） |
| **M2-Q6** | 数据面网关（ADR-22，单机进程内）流式 + 签名 URL 是否成立 | ✅ 通过 | 独立网关 listener（`--gw-addr`）；`POST /ticket` 签发一次性 HMAC-SHA256 签名 URL，网关无状态验签 + 未过期 + 一次性（nonce 消费）；exec/文件/日志经 ticket 换直连；`--gw-reconcile` 篡改/过期/重用均拒 + 端口暴露取到 VM 内服务 + 零残留（W10） |
| **M2-Q7** | PTY 交互式 shell + 端口暴露端到端 | ✅ 通过 | `Pty{cols,rows}` 帧 + sl-envd `forkpty`（guest 挂 devpts）；host→guest 帧化 stdin/resize，guest→host 裸 PTY 输出；`--pty-reconcile`：echo 双向流 + `stty size`=40 120（窗口 resize 生效）+ 会话收敛 + 零残留。端口暴露 `/gw/p` HTTP 反代 over vsock（W10/W11） |
| **M2-Q8** | allow-network 构建（ADR-19 + jailer-netns）能否支撑真 Python + 依赖（**还 M1 债**） | ✅ 通过 | `build_network` 三档；allow-all 构建沙箱 boot 进具名 netns（veth+tap+host NAT）→ RUN 真出口；真 OCI python:3.12-slim + pip install 依赖模板构建通过。CI `build-egress` job（W3） |
| **M2-Q9** | keepalive 续期端点（FR-1.2）在线可续、不越硬顶（**还 M1 债**） | ✅ 通过 | `POST /keepalive` 滑 idle lease 窗；TTL 绝对硬顶 keepalive **救不了**（`--orch-reconcile` ④ TTL 案例）。REST + SDK `keep_alive`（W2） |
| **M2-Q10** | SLO 裸金属化——创建/恢复分位 + 密度 ≥200@默认/≥500@micro（**还 M1 债**） | ⏳ 裸金属待补 | 方法学与 gate 就位：`bench-density.sh` 产 max_instances 曲线 + `DENSITY_MIN` gate；`bench-density` job（self-hosted bare-metal，schedule/dispatch）。**无 64C/128G runner 注册**（D4），真实密度数据待补；口径不下调（PRD §8.1） |
| **M2-Q11** | 快照加密（ADR-15，信封 + 分块 AEAD） | ⏸ 移 M3 | 按 D1「最外层可砍项，滑期即移 M3」显式砍出 M2。M2 主线（两硬出口 + Q1–Q9/Q12）已全绿，加密不阻塞出口 |
| **M2-Q12** | OCI 镜像当 rootfs 来源（ADR-18，ureq+rustls 手写 registry v2） | ✅ 通过 | `--oci-pull docker://python:3.12-slim` 拉取+digest 校验+layer flatten（whiteout/opaque）+bake ext4；`from=<OCI>` 模板 boot 起 Python；docker-archive 本地源。匿名+单架构 MVP。CI `oci` job（W3） |

## 4. M3 开工闸门（结论：可进入 M3）

对照砍单预案确认 M3 范围（PRD M3 行）：

- **集群化**：etcd 选主 + orchestrator 多副本 active-standby（ADR-17）+ 节点健康/失联自动回收；`sl-store` 切 etcd 实现（窄接口已备）。
- **数据面网关拆独立进程副本**：M2 已把 ticket/HMAC 无状态验签 + 一次性钉死接口边界（ADR-22），M3 拆分零语义变更；nonce 集随网关副本（文档已标）。
- **多租户面**：API Key/配额/审计 + mTLS（M2 本地环回无鉴权）。
- **可观测性全量**：指标/追踪/日志聚合。
- **移入 M3 的 M2 拉伸/待补项**：快照加密（ADR-15，M2-Q11）+ 完整保留期/版本钉住（ADR-16）；SLO 裸金属密度实测（M2-Q10，需 64C/128G runner）；域名粒度白名单 FR-3.2b / DNS 审计 FR-3.4。
- **Go 复审**：M2 维持全 Rust（D3）；M3 集群拆分（gw/orchestrator 独立副本）时按 ADR-3 闸门复审是否引 Go。

## 5. 已知局限（诚实记录，移交 M3）

- **快照加密未实现**（M2-Q11 移 M3）：当前 vmstate/mem 明文落盘。
- **裸金属密度数据缺**（M2-Q10）：无 self-hosted 64C/128G runner；`bench-density` job + `DENSITY_MIN` gate 就位，待 runner 注册产出 SLO 口径。
- **gVisor 能力集空**：短任务路径，无 pause/prebake/fork（能力对等而非功能对等，ADR-14/D2）；网络需 root netns（rootless `--network=none`）；SLO 待 M3 依契约测试补。
- **数据面网关**：MVP 端口反代仅简单 HTTP/1.0 GET；PTY 为 guest 机制 + host 对账（用户面交互 `exec -it` 网关透传留后）；单机进程内（M3 拆副本）。
- **AEAD 分块 / userfaultfd 懒加载**：随加密移 M3（P2）。
